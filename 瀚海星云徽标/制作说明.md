# 制作与检查

项目使用 Node.js、Canvas、ag-psd、OpenType.js、VTracer、OpenCV 和 psd-tools。依赖保存在项目内部，`work` 保存几何数据及检查结果。

在 Windows 上安装 Node.js/npm 与 Python 3.12 并加入 PATH 后，运行 `scripts/setup.ps1` 准备依赖和字体，运行 `python scripts/prepare.py` 提取随附参考图的结构，再运行 `npm run build` 生成文件。完整命令见仓库根目录 [制作指南](../DEVELOPMENT.md)。

运行 `npm run verify` 检查 PSD 图层、文字属性、路径、几何间距和像素一致性。运行 `scripts/verify_independent.py` 使用 psd-tools 独立读取 PSD，检查图层类型、文字和合成图，并使用 OpenCV 比较梅花轮廓。

Python 脚本使用项目的 `.python-deps`；Node.js 脚本使用项目的 `node_modules`。PNG 和 PSD 使用同一组图层生成，PNG 为 RGB，PSD 为 RGB、每通道 8 位。

PSD 的弧形文字使用逐字旋转的文字图层。中文使用 Google Fonts 提供的志莽行书，许可文件为 `assets/fonts/OFL-ZhiMangXing.txt`。

本机没有用于验收的 Photoshop。检查范围为文件结构、文字和形状属性、几何关系及像素数据；Photoshop 内的实际显示与编辑效果尚未验证。ag-psd 官方说明新增文字图层首次在 Photoshop 打开时可能提示更新文字。

参考资料：[ag-psd](https://github.com/Agamnentzar/ag-psd)、[志莽行书](https://github.com/google/fonts/tree/main/ofl/zhimangxing)、[VTracer](https://github.com/visioncortex/vtracer)。
