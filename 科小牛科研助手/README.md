# 科小牛科研助手

投稿时使用 `科小牛科研助手_白色背景.png` 和 `科小牛科研助手.psd`，并按问卷要求填写 `设计说明.md` 与 `AI辅助创作说明.md` 中的内容。

`科小牛科研助手_透明背景.png` 适合放入平台页面或其他背景中。两张图片和 PSD 均为 2048×2048，采用 sRGB 色彩。

PSD 包含 13 个命名图层。使用支持 PSD 图层的软件打开后，可以分别移动、隐藏或替换眼镜、眼睛、嘴巴、服装、四肢和字样。图层中的左右方向按人物自身方向命名。隐藏白色背景图层即可保留透明背景。

`制作素材` 保存生成图片、独立部件、提示词及文件检查结果；`制作工具` 保存分层制作和检查程序。

重新制作与检查的环境安装及运行命令见 [制作指南](../DEVELOPMENT.md)。投稿状态与作品使用边界见 [仓库首页](../README.md#投稿状态与权利说明)。
